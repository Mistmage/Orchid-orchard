# Implementation

Legend for implementation notes, tools, and future work.

## Structure

- `Tools/` — tooling notes (install, usage, future).
- `Tools/Future/` — tools worth adopting later, not now.

## Convention

Every note in this folder uses YAML frontmatter with at least:
- `topic`: short topic name
- `type`: note | tool | future | legend
- `status`: active | planned | deferred

Related notes link via `related:` list of paths.
