# Final goal — Lilac v1

Cross-browser extension storing tab collections as Markdown/YAML records via a
minimal native helper. Human-readable, Git/Syncthing-friendly, searchable,
editable outside the browser, reopenable from any browser. Browser storage
contains only UI preferences; all user data in portable files. (Per spec.)
